# AI-ML Service Template

A production-shaped starting point for an AI/ML backend service: a FastAPI HTTP API,
an optional async worker for slow or batch jobs, a config system split cleanly into
secrets and non-secret settings, and a swappable LLM provider layer behind one
interface.

This documentation describes the **complete system as generated by this template** —
every component and service the generation questions offer. A real generated project
only ships the code for what was actually selected; the sections below call out which
parts are optional so you can map this documentation onto whichever combination your
project chose.

---

## What can be generated

The template's `copier.yml` asks two kinds of questions:

**Components** — independent infrastructure primitives:

| Component | What it adds |
|---|---|
| Backend | A FastAPI HTTP API (`app/main.py`, `app/api/`) |
| Database | PostgreSQL + SQLAlchemy async + Alembic migrations |
| Worker | RabbitMQ + a durable async job runtime (submit now, process later, poll for result). Only offered when Database is selected |
| Cache | A small Redis client wrapper |
| Observability | Langfuse LLM tracing + OpenTelemetry + Prometheus metrics |
| Docs site | This MkDocs Material site |

**Services** — business-capability modules built on the components above:

| Service | What it adds |
|---|---|
| Auth | `X-API-Key` header authentication, backed by Postgres. Only offered when Database is selected |
| AI | An LLM provider abstraction, a small conversational agent, and an LLM-as-judge evals harness for scoring its output |

If a component or service is declined at generation time, its entire subtree is
deleted by a post-generation cleanup script — a generated project only ever contains
the code for what it actually chose. This docs site itself is one of those optional
components (`include_docs_site`): when it exists at all, it describes the template's
full capabilities, not a specific generation's subset.

## Technology stack

| Layer | Technology |
|---|---|
| Runtime | Python 3.13, FastAPI, Uvicorn |
| Database | PostgreSQL (SQLAlchemy 2.0 async + asyncpg), Alembic migrations |
| Async messaging | RabbitMQ (`aio-pika`) |
| Cache | Redis |
| LLM | Azure OpenAI, OpenAI, or Ollama — one config value swaps providers |
| Agent framework | LangGraph + LangChain |
| Observability | Langfuse (LLM traces), OpenTelemetry (spans), Prometheus (metrics), structlog (JSON logs) |
| Package manager | `uv` |

!!! note "Everything above is optional except the runtime itself"
    Database, Worker, Cache, Observability, Auth, and the AI service are all
    independently togglable at generation time. See `copier.yml` at the template root
    for the exact questions and defaults.
